# Contributing to Sandblizzard Rewards

Thank you for your interest in contributing to Sandblizzard Rewards!

## Beta Testing Trail

This project is part of the Sandstorm Solana Hackathon beta testing phase.

### Wallet Connection

To participate in the reward system:

1. Connect your Solana wallet to [Sandblizzard Bridge](https://sandblizzard.one/bridge)
2. Link your GitHub profile through the bridge
3. Your wallet address will be registered for reward distribution

### Getting Started

1. **Fork** this repository
2. **Clone** your fork locally
3. **Install dependencies**: yarn install
4. **Run tests**: nchor test --skip-deploy
5. **Create a branch** for your changes
6. **Submit a PR** with a clear description

### Contribution Guidelines

- Follow existing code style (see .prettierrc and 	sconfig.json)
- Write tests for new functionality
- Document your changes in the PR description
- Reference the issue number in your PR title
